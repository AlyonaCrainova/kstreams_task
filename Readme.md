Описание классов:

Message - класс сообщения.
MessageSerializer - сериализатор.
MessageDeserializer - десериализатор.
MessageSerdes = serdes класса Message.
FilterKafkaStreamsApp - приложение потоковой обработки. Создает топики, записывает тестовые данные в топики, заполняет топологию: реализует логику блокировки и модерации сообщений.
BlockedUsersProcessor - процессор блокировки сообщений. Проверяет в State Store наличие блокировки по ключу отправитель:получатель. Если значение найдено, считаем, что оно обработано, если нет, передаем дальше по топологии.
BannedWordsProcessor - процессор модерации сообщений. Выбирает из State Store список забаненных слов и маскирует их в сообщении на символ "*".

Инструкция по запуску:

Собираем java-проект, меняем путь к JAR в DockerFile при необходимости.
В терминале Docker desktop выполняем переход в папку с проектом: cd <путь к папке>. Запускаем кластер через команду терминала: docker compose up.
Для проверки можно перейти в Kafka ui Topics: в filtered_messages будут сообщения из messages за исключением тех, что совпадают по ключу с списком в blocked_users. В теле сообщений filtered_messages слова из banned_words будут заменены на символ "*".
Топики и тестовые данные генерируются из приложения.
